# Apply Offer

Review and apply pending structural offers generated by Auto Context.

## Arguments

- No argument: list all pending offers, ask user to select
- `{id}`: apply specific offer by ID (e.g., `/cac-apply 001`)
- `all`: apply all pending offers sequentially

## Procedure

### Step 1: Scan pending offers

1. Read all `.md` files in `.claude-auto-context/offers/`
2. Filter: skip files containing the line `applied`, `rejected`, or `failed`
3. Remaining files are pending offers

### Step 2: No argument — interactive selection

1. Display numbered list of pending offers (ID + title)
2. If 0 pending: output "대기 중인 offer가 없습니다." and stop
3. Use AskUserQuestion to let user select which offer(s) to apply

### Step 3: Apply selected offer

For each selected offer:

1. Read the full offer file
2. Identify the proposal section (`## Proposal` or `## Proposed Remediations` or any section describing what to change)
3. Execute the proposed changes:
   - Read target files mentioned in proposal
   - Apply the suggested modifications (Write/Edit)
   - If proposal involves file splits: create new files, update imports
4. Verify: run existing tests if available (`bun test`, `npm test`, etc.)
5. Update the offer file: append status block at the end
6. Output summary of changes made

### Step 4: `all` argument

Repeat Step 3 for every pending offer, sequentially.
Stop on first failure and report which offer failed.

## Status Update Format

After applying, append to the end of the offer file:

```markdown

## Status
applied

## Applied At
{ISO 8601 timestamp}

## Changes Made
- {file}: {description}
- {file}: {description}
```

## Error Handling

- If offer references files that don't exist: skip with warning
- If tests fail after applying: revert changes, mark offer status as `failed` instead of `applied`, report to user
- If offer is ambiguous: ask user for clarification before proceeding

## Anti-Patterns

- Do NOT apply without reading the full offer first
- Do NOT skip test verification if tests exist
- Do NOT modify the offer's Problem/Evidence sections
- Do NOT apply an offer that is already `applied`, `rejected`, or `failed`
