# Create Skill from Detected Pattern

Review pending skill-prompt files generated by Auto Context's skills-agent and delegate to skill-creator to produce high-quality SKILL.md files.

## Arguments

- No argument: list all pending prompt files, ask user to select
- `{slug}`: process specific prompt file matching the slug (e.g., `/cac-create-skill edit-test-commit`)

## Procedure

### Step 1: Check skill-creator availability

1. Run: `command -v skill-creator`
2. If not found, output:
   ```
   skill-creator not found. Install from https://github.com/anthropics/skills
   ```
   and STOP.

### Step 2: Scan pending prompt files

1. Read all `.md` files in `.claude-auto-context/skill-prompts/`
2. Filter: skip files containing the bare line `applied`, `rejected`, or `failed`
3. Remaining files are pending prompt files

### Step 3: No argument -- interactive selection

1. Display numbered list of pending prompt files (timestamp + slug extracted from filename)
2. If 0 pending: output "No pending skill prompts found." and STOP
3. Ask user to select which prompt to process

### Step 4: Process selected prompt

1. Read the full prompt file content
2. Run: `skill-creator <prompt_file_path>`
3. If skill-creator exits non-zero:
   - Append `## Status\nfailed` to the prompt file
   - Output error details and STOP

### Step 5: Locate generated SKILL.md

1. After skill-creator completes, identify the generated SKILL.md path
   - Check skill-creator stdout for the output path
   - If not reported, scan `.claude/skills/` for the newest SKILL.md file
2. Read the generated SKILL.md and display a summary to the user

### Step 6: Mark prompt file as applied

1. Append to the end of the prompt file:
   ```markdown

   ## Status
   applied

   ## Applied At
   <ISO 8601 timestamp>

   ## Generated Skill
   <path to generated SKILL.md>
   ```

### Step 7: Output summary

Report:
- Skill name and description
- SKILL.md file path

## Error Handling

- If `.claude-auto-context/skill-prompts/` directory does not exist: output "No skill-prompts directory found. The skills-agent has not run yet." and STOP
- If skill-creator is not installed: output install guidance and STOP
- If skill-creator fails: mark prompt as `failed`, report error

## Anti-Patterns

- Do NOT invoke skill-creator without user confirmation of which prompt to process
- Do NOT modify the prompt file's content sections (What/When/Why/When-NOT) -- only append status
