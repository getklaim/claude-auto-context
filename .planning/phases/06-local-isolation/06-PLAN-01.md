# Plan 01: Setup Hook — Create .claude/rules/local/ and Add to .gitignore

<objective>
Ensure the plugin setup hook creates the `.claude/rules/local/` directory in the target project and adds it to `.gitignore`, so auto-generated rules are never tracked by git.
</objective>

<tasks>

<task id="1">
<title>Add local rules directory creation to setup.sh</title>
<read_first>
- scripts/setup.sh
</read_first>
<action>
After the existing Bun install block (line 11, before `exit 0`), add:

```bash
# Ensure local rules directory exists (auto-generated rules go here)
PROJECT_DIR="${CLAUDE_PROJECT_DIR:-$(pwd)}"
mkdir -p "$PROJECT_DIR/.claude/rules/local"
```

This uses `mkdir -p` which is idempotent — safe if directory already exists.
</action>
<acceptance_criteria>
- `grep -q 'mkdir -p.*\.claude/rules/local' scripts/setup.sh` succeeds
- `grep -q 'CLAUDE_PROJECT_DIR' scripts/setup.sh` succeeds
</acceptance_criteria>
</task>

<task id="2">
<title>Add .gitignore entry for .claude/rules/local/</title>
<read_first>
- scripts/setup.sh
</read_first>
<action>
After the mkdir command from task 1, add an idempotent .gitignore append:

```bash
# Add .claude/rules/local/ to .gitignore (idempotent)
GITIGNORE="$PROJECT_DIR/.gitignore"
ENTRY=".claude/rules/local/"
if [ -f "$GITIGNORE" ]; then
  grep -qxF "$ENTRY" "$GITIGNORE" || echo "$ENTRY" >> "$GITIGNORE"
else
  echo "$ENTRY" > "$GITIGNORE"
fi
```

Key: `grep -qxF` does exact full-line match, preventing duplicate entries. If `.gitignore` does not exist, it creates one.
</action>
<acceptance_criteria>
- `grep -q 'grep -qxF.*\.claude/rules/local/' scripts/setup.sh` succeeds
- `grep -q '\.gitignore' scripts/setup.sh` succeeds
</acceptance_criteria>
</task>

</tasks>

<verification>
1. Run `bash scripts/setup.sh` in a temp project dir
2. Verify `.claude/rules/local/` directory exists
3. Verify `.gitignore` contains `.claude/rules/local/`
4. Run `bash scripts/setup.sh` again — verify `.gitignore` does not have duplicate entry
</verification>

<must_haves>
- .claude/rules/local/ directory created on plugin load
- .gitignore entry added idempotently
- Existing .gitignore content preserved
</must_haves>
