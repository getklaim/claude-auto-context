# Plan 03: Suggestion Naming — YYYYMMDD-HHMMSS Timestamp Format

<objective>
Change suggestion file naming from sequential `{NNN}-{slug}.md` to timestamp-based `YYYYMMDD-HHMMSS-{slug}.md`, eliminating cross-machine naming conflicts.
</objective>

<tasks>

<task id="1">
<title>Update create-suggestion SKILL.md naming convention</title>
<read_first>
- skills/create-suggestion/SKILL.md
</read_first>
<action>
In `skills/create-suggestion/SKILL.md`:

1. Replace all `{NNN}-{slug}.md` references with `YYYYMMDD-HHMMSS-{slug}.md`
2. Replace the Procedure section with:

```markdown
## Procedure

1. Read existing suggestions in `.claude-auto-context/suggestions/` to avoid duplicates
2. Generate timestamp for filename: `YYYYMMDD-HHMMSS` format using current UTC time (e.g., `20260323-143052`)
3. Analyze session data for structural patterns
4. For each candidate:
   a. Verify 3+ sessions
   b. Compute quantitative metrics
   c. Formulate specific, actionable proposal
5. Write the suggestion file as `YYYYMMDD-HHMMSS-{slug}.md`
```

3. Update the "Output Format" section example:
   From: `Create files in .claude-auto-context/suggestions/ as {NNN}-{slug}.md:`
   To: `Create files in .claude-auto-context/suggestions/ as YYYYMMDD-HHMMSS-{slug}.md:`

4. Remove any reference to "get next sequence number" — timestamps don't need sequencing.
</action>
