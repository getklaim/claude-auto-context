# Plan 07: Prompt Hook — Timestamp Detection + Delete update-claudemd Skill

<objective>
Update on-user-prompt-submit.sh to detect timestamp-named suggestion files (YYYYMMDD-HHMMSS format) instead of sequential numbers. Delete the update-claudemd skill directory entirely (completing claudemd-agent removal).
</objective>

<tasks>

<task id="1">
<title>Update suggestion detection in on-user-prompt-submit.sh</title>
<read_first>
- scripts/on-user-prompt-submit.sh
</read_first>
<action>
Replace the ID extraction block with timestamp-aware logic:

Replace:
```bash
    # Extract numeric ID from filename (e.g., 001-slug.md -> 001)
    ID=$(basename "$f" .md | grep -o '^[0-9]*')

    PENDING_TITLES+=("$ID. $TITLE")
```

With:
```bash
    # Extract timestamp ID from filename (e.g., 20260323-143052-slug.md -> 20260323-143052)
    ID=$(basename "$f" .md | grep -oE '^[0-9]{8}-[0-9]{6}')
    [ -z "$ID" ] && continue

    PENDING_TITLES+=("[$ID] $TITLE")
```

Key changes:
- Regex changed from `'^[0-9]*'` to `'^[0-9]{8}-[0-9]{6}'` (matches YYYYMMDD-HHMMSS)
- Skip files that don't match timestamp pattern
- Display format changed from `$ID. $TITLE` to `[$ID] $TITLE`
</action>
<acceptance_criteria>
- `grep -q '[0-9]\{8\}-[0-9]\{6\}' scripts/on-user-prompt-submit.sh` succeeds
- `grep -q 'timestamp ID' scripts/on-user-prompt-submit.sh` succeeds
</acceptance_criteria>
</task>
