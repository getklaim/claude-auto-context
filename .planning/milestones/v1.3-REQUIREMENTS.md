# Requirements: Claude Auto Context

**Defined:** 2026-03-24
**Core Value:** 실제 사용 패턴을 추출하여 Claude Code의 프로젝트 이해도를 지속적으로 개선

## v1.3 Requirements

Skill auto-generation milestone. skill-agent가 세션 패턴을 감지하고, skill-creator용 프롬프트를 조합하여, 자동으로 고품질 스킬을 생성.

### Detection (감지)

- [ ] **SDET-01**: skill-agent가 3+세션에 걸쳐 동일 의도 프롬프트 → 동일 도구 시퀀스 패턴을 감지 (H-SKILL-01: Jaccard>0.5, LCS>=5)
- [ ] **SDET-02**: 복합 동작 프롬프트("수정하고 커밋하고 푸시") 파싱으로 동사 체인 추출 (H-SKILL-03)
- [ ] **SDET-03**: 네거티브 휴리스틱으로 거짓 양성 필터링 — 순수 탐색, 디버깅 스파이럴, 단일 파일 편집, 플러그인 내부 경로 제외 (H-SKILL-05)
- [ ] **SDET-04**: 스코어링 공식으로 후보 평가 (score >= 10 AND sessions >= 3이면 생성, 5-10이면 관찰 저장)
- [ ] **SDET-05**: skill vs rule vs hook 분류 결정 트리 — 5+도구호출+NL트리거+의사결정 = skill, 나머지는 기존 agent에 위임
- [ ] **SDET-06**: 자기참조 필터 — 스킬 호출 이벤트, `.claude/` 경로 이벤트를 패턴 집계에서 제외

### Prompt Composition (프롬프트 조합)

- [ ] **SPROM-01**: 감지된 패턴에서 skill-creator용 프롬프트 조합 — what(스킬이 할 일), when(트리거 조건), why(자동화 가치)
- [ ] **SPROM-02**: 실제 세션의 프롬프트/도구시퀀스를 예시로 포함 (구체적 파일명/명령어는 일반화)
- [ ] **SPROM-03**: 시크릿/크레덴셜 자동 치환 — `sk-ant-*`, `Bearer *`, IP주소, 패스워드를 `${PLACEHOLDER}`로 교체
- [ ] **SPROM-04**: 프롬프트에 "When NOT to use" 조건 포함 (리서치 결과: 네거티브 예시가 트리거 정확도 핵심)

### Integration (통합)

- [ ] **SINT-01**: skill-agent가 기존 3-agent orchestrator와 별도 query() 호출로 실행 ($0.50 예산, maxTurns: 8)
- [ ] **SINT-02**: skill-agent가 매 3번째 배치에서만 실행 (워크플로 패턴은 느리게 변함)
- [ ] **SINT-03**: 기존 observations 테이블 재사용 — `pattern_key LIKE 'skill:%'`, `agent_source='skill-agent'`
- [ ] **SINT-04**: buildBulkPrompt() 출력 + 기존 스킬 목록(이름+설명)을 skill-agent에 전달
- [ ] **SINT-05**: 프로젝트당 자동생성 스킬 5개 하드캡 — `skills-registry.json`으로 추적

### Delivery (전달)

- [ ] **SDEL-01**: skill-agent가 프롬프트를 `.claude-auto-context/skill-prompts/YYYYMMDD-HHMMSS-{slug}.md` 파일로 저장
- [x] **SDEL-02**: `/cac-create-skill` 스킬이 대기 중인 프롬프트 파일 목록을 보여주고 선택시 skill-creator 호출
- [ ] **SDEL-03**: 플러그인 setup hook이 skill-creator 설치 여부 확인, 미설치시 `anthropics/skills` 리포에서 sparse checkout으로 자동 설치
- [x] **SDEL-04**: 스킬 생성 완료 후 skills-registry.json 업데이트 (이름, 생성일, 소스 세션)
